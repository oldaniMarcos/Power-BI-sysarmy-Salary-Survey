# Sysarmy Salary Survey Dashboard

<img width="1344" height="756" alt="powerbi_sysarmy" src="https://github.com/user-attachments/assets/46a1c048-8afa-4057-9f7d-3ffab45fd037" />

This is an interactive dashboard built with Power BI using data from the **Sysarmy Salary Survey**.

## Features

* Extensive data preparation and transformation using Power Query.
* Use of DAX measures.
* Relationships between datasets for analyzing multi-valued fields such as technologies and frameworks.
* Interactive filtering and drill-down.

## Pages

### Salaries

Analysis of gross salaries across different dimensions, including:

* Salary ranges
* Average and median gross salary
* Seniority
* Years of experience
* Location
* Contract Type
* Gender
* Years in current position

### Profiles & Employment

Analysis of professional and employment characteristics:

* Seniority
* Organization size
* Work modality
* Job-seeking status
* Multiple employment
* Contract type
* Location

### Education

Analysis of educational background:

* Education level
* Education status
* Median gross salary per education level
* Median gross salary per seniority level
* Education level and status slicers

### Technologies

Analysis of technologies reported by respondents:

* Programming languages and technologies
* Frameworks and libraries
* Platforms
* Databases

## Data Preparation

Power Query was used to clean and transform the data, create ranges, normalize multi-valued fields, and prepare the data model for analysis.

The dashboard uses gross salary as the primary salary metric. Net salary was not used due to missing and inconsistent values.

## Data Source

The dataset comes from the Sysarmy Salary Survey, an Argentine survey focused on salaries and professional characteristics within the technology industry.
